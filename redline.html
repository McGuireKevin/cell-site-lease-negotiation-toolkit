Opening a .docx reads it directly — the text, the formatting, any comments, and tracked changes if they used them, which is better than any diff because it is what they actually did rather than what a comparison infers. A .pdf is inspected and reported on: it carries no styles, so it can never answer the formatting question.

Round N is compared against round N−1, not against the original draft. Comparing every round to the first draft re-reports everything already dispositioned, which is how a reviewer learns to skim the list.
